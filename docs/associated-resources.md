# 照片、XMP 与 Live Photo

1.3.0 在手动扫描与归档中使用素材组：先确定关联成员及共同名称，再复制。原文件的内容、名称和内部元数据不会改写。

## XMP 随照片归档

支持同一来源目录内的两种命名：

| 照片 | 配套 XMP | 结果 |
|---|---|---|
| `IMG_001.CR3` | `IMG_001.xmp` | 随 RAW 照片进入其图片目录 |
| `IMG_001.jpg` | `IMG_001.jpg.xmp` | 保留含原扩展名的命名约定 |
| 唯一 `IMG_001.CR3` 与唯一 `IMG_001.jpg` | `IMG_001.xmp` | 两张照片分别归档，共享 XMP 在各自目的地保存副本 |

名称匹配考虑所在目录，不能跨来源目录仅凭名称混配。多个同类照片、多个 XMP 或未支持的编辑版本名（如 `IMG_001.CR3_01.xmp`）不会被随意解释，相关 XMP 或组进入待处理。

RAW 与非 RAW 沿用所选目录规则。发生目标名称冲突时，照片与关联 XMP 一起采用带标识的主文件名；含原扩展名的 XMP 继续保留该命名结构。

## Live Photo 按标识配对

读取照片的 Apple ContentIdentifier 和视频的 Keys ContentIdentifier。一个标识对应唯一照片及唯一视频时才配对；照片和视频即使名称不同，也可以组成一组。

配对成功后，视频进入照片规则确定的图片目录，使用照片主文件名，例如：

```text
图片/iPhone 15 Pro/非RAW/2026/10/
├── IMG_001.heic
├── IMG_001.mov
└── IMG_001.heic.xmp   （源目录中有明确关联 XMP 时）
```

同名照片和视频不足以确认 Live Photo。有线索但缺少成员、标识缺失、重复或冲突时进入待处理；没有关联线索的普通照片与独立视频继续原有分类。

真实 HEIC/MOV 成对样例验证了标识读取、配对、共同目录与内容一致。尚未逐项验证所有设备及导出格式，也未将本版归档结果导入 Apple Photos 等软件播放。同目录与同名不构成播放保证；应用不重建或转码 Live Photo。

## 检查完整计划

1.3.1 在“确认预览”和任务详情中提供完整计划，可以翻页查看全部素材组，并选择“只看待处理项”。点击素材组展开成员，关联依据与完整路径可单独展开。预览首页突出源文件数、预计复制容量、重复副本和待处理组，其余统计位于“本次设置与详细统计”。

- 物理文件：源目录中的不同文件数量。
- 成员副本：需要核对的目的地成员数量；共享 XMP 可对应多个副本。
- 素材组：需要共同判断关联和命名的集合，独立素材也单独计组。
- 待处理：关联不明、资源缺失或版本政策待确认，与等待复制和 IO 失败区分。
- 预计复制容量：扫描时计划新增成员的字节数，扣除目标中已确认重复的成员；待处理项没有自动复制计划。

扫描和复制期间设置不可编辑。预览后修改目录、规则或设备映射，会提示重新扫描，旧计划不能直接按新设置开始。历史任务可查看其实际设置。

## 重复、变化与恢复

照片已有相同副本并不代表配套齐全。新增 XMP 或晚到的 Live Photo 视频需要重新扫描；系统逐成员核对目标内容。唯一已有照片的实际名称可用于补齐对应配套，完整相同组再次运行不产生无意义副本。去重范围限制在当前规则确定的目标目录。

已有 XMP 内容不同、存在多个既有照片名称等情况，会列为待处理。自动保留哪一整组版本或如何更新历史尚未确定，本版不会静默覆盖、删除旧副本或声称整组重复。

组成员逐个提交，部分复制成功不等于整组完整。成员失败、取消或中断后，已完整提交的副本保留；继续/重试会复核已完成成员并补齐缺失副本。源素材变化或目标被其他程序占用时，会说明失败原因，需要检查后重新扫描。未完成隐藏临时副本不参与成功去重。

## 从旧版本升级

从 1.3.0 升级到 1.3.1 仅更新界面和交互，无需数据迁移，原有素材组规则保持不变。以下重新扫描配套资源的建议主要适用于 1.2.0 的历史单文件任务。

1. 正常结束或取消当前任务，备份应用状态（Docker 的宿主 config，或飞牛应用数据）。
2. Docker 改用 `superdaxigua/material-archiver:1.3.1`，保留原挂载后 pull/up；飞牛使用新版 FPK 升级并保留应用数据。
3. 登录并核对原有目录与任务。旧单文件任务仍可查看，但会提示未验证新配对规则。
4. 对需要配套整理的源目录重新扫描，检查完整计划及待处理项，再手动开始。

不需要卸载应用、清空输出目录或重新创建账号。此次发布不自动升级你的 NAS 实例。
